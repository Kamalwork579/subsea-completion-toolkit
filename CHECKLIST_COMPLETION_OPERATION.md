# Completion Operation Checklist

**Document:** `CHECKLIST_COMPLETION_OPERATION.md`  
**Well Type:** Subsea Deepwater / Horizontal Producer  
**Standard:** API 17D | API RP 16D | NORSOK D-010  
**Revision:** 3.1 — June 2026

> ★ **CRITICAL** items require written sign-off from both the Operator Company Representative and the Contractor Supervisor before the next operation may proceed.

---

## Phase 1 — Pre-Job Planning & Mobilisation

- [ ] ★ HAZID / HAZOP completed, all actions closed and signed off
- [ ] ★ Well Programme reviewed by Completion Engineer and OIM — revision date confirmed
- [ ] Equipment matrix completed — all completion tools and accessories verified on location
- [ ] ★ Management of Change (MOC) approved for any deviation from Well Programme
- [ ] Completion string design approved — tubing grade, weight, connection confirmed vs. H₂S / CO₂ partial pressures (NACE MR0175)
- [ ] ★ BOP stack function tested and pressure tested to MAWHP — low and high test recorded
- [ ] Completion fluid specification confirmed: density, pH, filtration (<2 NTU), compatibility with formation and elastomers
- [ ] Chemical inventory on location: MEG, biocide, corrosion inhibitor, scale inhibitor
- [ ] Crane/lifting certificates current — all completion tools within SWL
- [ ] Personnel competency verified: SCSSV specialist, gravel pack operator, chemical injection operator
- [ ] ★ Emergency response plan (ERP) briefed to all personnel — muster station, nearest rig escape and rescue

---

## Phase 2 — Wellbore Preparation

- [ ] ★ Wellbore confirmed clear to TD — bit run or gauge run completed; minimum drift confirmed per programme ID
- [ ] Caliper log reviewed — no significant washouts or tight spots that would affect screen/packer placement
- [ ] ★ Casing pressure test completed — 70 bar low (5 min hold), full MAWOP high (10 min hold) — result on file
- [ ] Wellbore clean-up circulation achieved — return fluid at surface: NTU ≤5, density within ±10 kg/m³ of pumped fluid
- [ ] Formation integrity test (FIT / LOT) result recorded — MAWOP confirmed not to exceed fracture gradient
- [ ] ★ Wellbore fluid density confirmed overbalanced vs. reservoir BHFP — minimum 200 psi (14 bar) overbalance
- [ ] Downhole temperature and pressure recorded for hydrate risk assessment

---

## Phase 3 — Lower Completion Run (Sand Control)

- [ ] ★ Screen assembly — MPI / dimensional checks complete, documentation on file per API 5CT
- [ ] Screen OD confirmed ≤ maximum drift of open-hole section — no-go confirmed
- [ ] ICD nozzle sizes confirmed per reservoir engineering recommendation — erosional velocity calculated using API RP 14E
- [ ] ★ All connection make-up torques recorded on running tally — within manufacturer's recommended range
- [ ] Centralizer programme executed — spacing per casing programme; landing calculation confirmed
- [ ] ★ Depth correlation confirmed — GR log marker match within ±0.5m before any screen release
- [ ] Screen release mechanism tested at surface — re-confirm function before running
- [ ] Gravel pack / frac pack execution parameters within design: rate, pressure, proppant concentration
- [ ] Returns at surface monitored throughout pack — screen-out confirmed at design pressure
- [ ] Lower completion tag-in confirmed — pipe weight on TD at expected depth ±1m

---

## Phase 4 — Upper Completion & Packer Setting

- [ ] ★ PBR / polished bore receptacle confirmed compatible with packer bore — OD / ID match
- [ ] ★ Packer set confirmed — weight indicator shift recorded; annulus pressure test across packer completed
- [ ] Production tubing tally and running record completed — joint-by-joint make-up on record
- [ ] ★ SCSSV installed at correct depth per Well Programme — control line run without damage
- [ ] SCSSV function test completed at surface: open on pressure, close on loss of pressure, re-open confirmed
- [ ] SCSSV control line pressure tested to 1.5× SCSSV MAWOP
- [ ] ★ Tubing hanger set and locked — tubing load calculation reviewed
- [ ] Tubing hanger plug installed and pressure tested per Phase C barrier matrix (Sect. 4 of WELL_CONTROL_BARRIERS.md)
- [ ] ★ Landing string pressure tested — tubing side and annulus side, full test matrix

---

## Phase 5 — Tree Installation & Connections

- [ ] ★ Subsea tree (XMT) inspected on deck — all valves stroked, all test ports confirmed
- [ ] XMT run on landing string — weight on XMT profile confirmed; XMT locked to wellhead
- [ ] ★ XMT pressure tested — all valves: PMV, PWV, AMV, crown valve — per test log template
- [ ] Umbilical connected — hydraulic, electrical, MEG and chemical lines identified and terminated
- [ ] Umbilical pressure tested — each line to rated pressure: 10 min hold, no observed loss
- [ ] ROV inspection of all connections — visual confirmation of lockdown on XMT profile
- [ ] ★ Dual-barrier Phase C status confirmed in writing before landing string pull
- [ ] Landing string retrieved — SSIV and BIV status confirmed before pulling through BOP

---

## Phase 6 — Well Test & Handover

- [ ] ★ Final pressure test report issued and countersigned by Operator Company Rep
- [ ] PITA (Pressure Integrity Test of Annulus) completed — annulus pressure held for 24 hours
- [ ] Well performance test completed — oil/gas/water rates on record
- [ ] Production log (PLT) or inflow profile test completed if required by Well Programme
- [ ] ★ Barrier status log current and verified at handover — no open actions
- [ ] DTS / PT monitoring confirmed operational in SCADA
- [ ] MEG injection rate confirmed and injection data logged in chemical management system
- [ ] Well handover certificate completed and signed — Operator Well Engineer and OIM
